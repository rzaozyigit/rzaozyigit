## About me

Embedded Software Engineer building reliable, field-proven firmware for defense systems.

I work on ARM (STM32) and PIC platforms, with hands-on experience in UART, I²C, SPI, CAN/CAN-FD, Ethernet, PWM/ADC and PI/PID control systems.

I care about modular software architecture, real-time performance and code that's easy to maintain. I also build Qt/C++ desktop tools for testing and configuring the hardware I work on.
